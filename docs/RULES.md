# 统一规则 v1.0.0

数值唯一来源为 [policy.json](../config/policy.json)，字段口径唯一来源为 [metrics.json](../config/metrics.json)。本文件解释语义，修改配置后须重建发布文件并运行测试。

## 当前发布模式

OBSERVATION。A/B可填写完整观察卡，但即使全部已定义条件成立也只能为OBSERVE。C/D为DISABLED。schema不接受PASS_RULES、份数和交易动作字段。不存在隐藏开关能在不改代码、schema、测试和版本的情况下变成交易评分系统。

| 状态 | 定义 |
|---|---|
| UNKNOWN | 身份、分类或必要证据不足 |
| FAIL | 有已验证的规则不满足项；不代表资产诈骗判定 |
| DISABLED | 在身份可核且没有共同硬否决的前提下，该类别关闭 |
| OBSERVE | 仅A/B，当前已定义观察条件有据；不代表买卖许可、投资安全或盈利能力 |

先检查结构与证据合法性；不合法的JSON不能成为有效观察报告。对合法记录：身份未知→UNKNOWN；已知共同否决→FAIL；类别冲突→UNKNOWN；NONE→FAIL；关闭类→DISABLED；类型已知否决→FAIL；必要字段缺失→UNKNOWN；其余→OBSERVE。否决返回后不重新分类，不分配份数。

## 共同条件

必须有实际市值、外盘状态、指定上下文卖出核验、捆绑/内部比例、fo、24h fo变化，以及规定X覆盖范围内的机器人/FOMO观察。`value=null`、过期、口径未核、冲突都属于未知。MC≤0、非外盘、卖出检查失败、bot_detected=true是已知否决；捆绑或内部>20%、fo>40%、24h变化>10pp、独立FOMO家族≥2也是否决。边界20、40、10不因该单条规则否决，仍需检查其他规则。

A首次观察需当时已获第三方费率/份额数字，不能用随后数据。B官方事件需0≤年龄<48h，市值<$50M；关注、发帖、上架分别描述，不扩大背书含义。没有原始官方时间就UNKNOWN。历史不足24h的资产无法补齐fo24h变化，在当前基线只能UNKNOWN，不用0填补。

## 分类与传播

语法多标签保存。纯LOTTERY为C。当前发布版混合LOTTERY只允许C或AMBIGUOUS，不能通过A/B/D绕行。A需要VACUUM/TANDEM/MECHANISM结构证据；B需要PERMISSION；D是已有对象二段阶段，始终关闭。B过期不能自动尝试D。

FOMO P2优先于P0/P1；中文覆盖不完整不能升P0/P1。覆盖完整且未检出只表示规定范围未观察到，不是中文全网不存在。种子利益线索未经当期核验只能UNKNOWN。模型判断独立性、语法和外部内容真假仍需要人工抽查。

## D：只保留未来设计，不开放功能

未来候选区间：MC [$300k,$3M]；fo [15,25]%；24h成交额/MC [0.3,2]；独立具名主体≥2或经核鲸鱼净主动买入>0；必须真实回撤、有效持仓对比、fo稳定方法及开发者卖出检查。具名OR鲸鱼按三值逻辑计算，任一已知true满足该条件，两false才false，其余unknown。

真实复核要求同资产、同规则版本、T1源观测时间晚于T0至少300秒；当前测试原语使用300–600秒窗口。**测试原语不是调度器，更不是复核全部市场数据的实现**。同轮复搜不满足、旧缓存换新抓取时间不满足。fo稳定/回撤等方法未统一认证，供应商能力和持久化未实测，D不会因本地边界测试通过而开放。

## 非本版承诺

不计算仓位、组合风险、退出动作、目标价或收益。没有接入持续监测。OBSERVE不是完整安全门：权限变更、流动性容量、未来税率和执行等风险尚不能由此发布包认证。未来扩展必须另立版本和测试集，不能仅改C_ENABLED/D配置。
