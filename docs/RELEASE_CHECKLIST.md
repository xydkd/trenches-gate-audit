# 发布与验收记录

本仓库发布材料和实际Grok任务启用分别验收。Python测试证明给定输入的逻辑与结构，不能证明实时搜索真实性或线上模型完全服从提示词。

## 本地发布检查

运行 `python scripts/check_release.py`，必须全部成功：

- 构建产物与配置、模板和schema逐字一致。
- 合成正向、缺失、空窗、失败示例合法，且清楚标为REPLAY。
- 已知硬否决不被后续分类覆盖；必要数据缺失不得OBSERVE。
- B时间/市值、共同阈值、D禁用谓词边界正确。
- C与混合LOTTERY不能经A/B/D绕行。
- 非EVM/错链/错CA、来源不适用、未来或旧快照、缺证据被拒绝。
- LIVE/REPLAY分离，私有源URL和交易动作被拒绝。
- 旧v0归档未被修改；Markdown相对链接能解析。
